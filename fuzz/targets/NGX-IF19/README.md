# NGX-IF19 — повторный HEADERS в существующем потоке HTTP/2

Цель повторно использует обвязку активного HEADERS из IF18, но имеет отдельный корпус: сначала передаётся HEADERS запроса, затем HEADERS в форме трейлеров для того же потока. nginx проверяет ID потока относительно `last_sid` и возвращает ошибку протокола соединения, не создавая новый поток и не декодируя второй блок HPACK. Таким образом, цель проверяет текущую границу отказа nginx, но не заявляет о разборе полей HTTP/2-трейлеров.

```sh
./fuzz/scripts/fuzz.sh smoke NGX-IF19 --max-len 8192
```

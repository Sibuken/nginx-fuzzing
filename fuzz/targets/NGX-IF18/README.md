# NGX-IF18 — от HEADERS HTTP/2 к активному запросу

Вход — ограниченная последовательность, начинающаяся с кадра HEADERS HTTP/2 в wire-формате; за ним могут следовать кадры CONTINUATION, каждый с девятибайтовым заголовком. Настоящая функция nginx `ngx_http_v2_state_head` направляет обработку в `ngx_http_v2_state_headers`, проверяет метаданные HEADERS, создаёт поток и запрос, затем передаёт блок HPACK настоящим обработчикам заголовков HTTP/2-запроса. Автомат обработки блока заголовков проверяет тип кадра CONTINUATION, ID потока и `END_HEADERS`. Начальные примеры сочетают CONTINUATION с флагами PADDED и PRIORITY, включая некорректную длину padding и усечённые метаданные приоритета. Минимальная таблица виртуальных имён содержит `fuzz.test` для поиска `:authority`.

Адаптер, используемый только фаззером, подавляет побочные эффекты финализации и выполнения запроса, а также уничтожает искусственный пул после разбора. Маршрутизация, тело запроса и фазы приложения не запускаются. Размер входа ограничен 8192 байтами; вход передаётся одним непрерывным доступным для записи буфером. Фрагментация сетевого чтения отдельно проверяется в NGX-IF15.

```sh
./fuzz/scripts/fuzz.sh smoke NGX-IF18 --max-len 8192
```

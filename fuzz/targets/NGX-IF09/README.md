# NGX-IF09 — парсер конфигурации

Цель передаёт данные из памяти настоящей функции nginx `ngx_conf_read_token`, обрабатывает все возвращённые аргументы и проверяет продвижение парсера. Затем те же данные проходят через публичный путь `ngx_conf_param` с обработчиком, принимающим все директивы. Так проверяются ветви парсера, но произвольные директивы модулей не исполняются.

Начальные примеры охватывают обычные директивы, кавычки, экранирование, переменные, комментарии, несколько инструкций, токены вложенных блоков и незавершённое значение. Небольшая обвязка, добавляемая только при сборке, открывает доступ к иначе статической функции токенизации; её реализация не копируется и не изменяется.

Это цель для проверки синтаксиса и безопасности памяти. Она не заявляет о семантическом покрытии всех директив nginx, обработке `include` и glob-шаблонов, дочитывании файла конфигурации или специфичных для модулей callbacks create/merge.

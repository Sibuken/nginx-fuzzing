# NGX-IF11 — заголовки кадров HTTP/2

Цель передаёт каждый последовательный префикс заголовка кадра настоящей функции nginx `ngx_http_v2_state_head`. Полные заголовки проверяют длину, флаги, ID потока, обработку известных типов и пропуск неизвестных.

Обвязка, добавляемая только при сборке, временно заменяет обработчики тела кадра на обработчик-заглушку. Поэтому эта цель проверяет кадрирование и диспетчеризацию, но не поток управления DATA, жизненный цикл потоков, влияние SETTINGS, блоки заголовков HPACK или формирование кадров ответа. Для этих путей нужны корректное соединение HTTP/2 и граф конфигурации nginx; узкая цель на них не претендует.

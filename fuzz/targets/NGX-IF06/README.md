# NGX-IF06

Эта узкая цель с необработанными входными данными нужна потому, что upstream HTTP-harness не покрывает парсер PROXY: его Unix-сокет не включает параметр `proxy_protocol`. Цель вызывает тот же публичный парсер, что и слушатели nginx, используя корректный журнал соединения и новый пул nginx для каждого тестового примера.

Парсер принимает один непрерывный заголовок версии 1 или 2; потокового режима нет. Проверяется, что ненулевой указатель результата остаётся внутри переданного буфера. Ожидаемый отказ на некорректных данных не считается находкой.

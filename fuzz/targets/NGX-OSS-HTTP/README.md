# NGX-OSS-HTTP

Эта цель — закреплённый по версии `http_request_fuzzer` из OSS-Fuzz. Каждый тестовый пример — сообщение `HttpProto` формата proto2 text, содержащее клиентский `request` и upstream-ответ `reply`. Макрос `DEFINE_PROTO_FUZZER` задаёт точку входа libFuzzer, пользовательский мутатор и скрещивание; nginx выполняется в процессе с адаптерами системных вызовов и ввода-вывода из upstream-проекта.

Встроенная конфигурация создаёт Unix-слушатель HTTP и проксирует запросы на искусственный upstream. Поэтому цель проверяет строку запроса HTTP/1, заголовки, нормализацию URI и обработку статуса и заголовков ответа upstream. Достижимость разбора chunked-кодирования и PROXY protocol измеряется, а не предполагается. TLS handshake и кадрирование HTTP/2/3 не проверяются.

Локальный патч добавляет явную обработку ошибок запуска. Он не меняет семантику исходников nginx и применяется только к изолированной копии для сборки.

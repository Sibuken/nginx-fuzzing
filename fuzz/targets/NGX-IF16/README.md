# NGX-IF16 — разбор pseudo-заголовков HTTP/2

Цель передаёт `:method`, `:scheme`, `:path`, повторяющиеся и неизвестные pseudo-заголовки настоящим функциям nginx проверки HTTP/2-заголовков и разбора pseudo-заголовков. Вход имеет компактный формат: байт длины имени, байт длины значения, байты имени, байты значения; записи повторяются до конца входа.

Для каждого входа создаются новый пул nginx и минимальные искусственные запрос и поток. Выполнение запроса не запускается. `:authority` и значения пути, которые могли бы привести к финализации ошибки URI, исключены: для них нужны конфигурация виртуального сервера или полный жизненный цикл запроса.

Запуск:

```sh
./fuzz/scripts/fuzz.sh smoke NGX-IF16 --max-len 4096
```

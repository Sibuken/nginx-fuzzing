# NGX-IF13 — кадры RST_STREAM HTTP/2

Цель передаёт последовательности кадров через настоящий инкрементальный парсер заголовков nginx и обработчик `ngx_http_v2_state_rst_stream`. Каждый вход повторяется с четырьмя схемами фрагментации; для каждого повтора создаётся новое искусственное соединение.

Изолированный драйвер, добавляемый только при сборке, создаёт минимальные активные потоки (ID 1 и 5), закрытый индексированный узел (ID 3), соединения запросов и пустые callbacks событий чтения. Так проверяются настоящие пути обновления состояния закрытия потока и ошибок, без разбора запроса и сетевого ввода-вывода. Пример `rst-closed-stream` отличает закрытый поток в индексе от отсутствующего ID 7 в `rst-unknown`. ID потока 0 и некорректные длины также проходят реальные ветви обработчика.

Другие кадры, содержащие запрос, и создание запроса из HEADERS не входят в эту цель.

# NGX-IF17 — преобразование заголовков HPACK в запрос HTTP/2

Цель передаёт необработанные блоки HPACK настоящей функции nginx `ngx_http_v2_state_header_block`. Искусственные активные запрос и поток заставляют каждое декодированное поле пройти через `ngx_http_v2_state_process_header`, включая проверку заголовков, разбор pseudo-заголовков и поиск `:authority` в минимальной таблице виртуальных серверов `fuzz.test`. После завершения блока обработка останавливается до `ngx_http_v2_run_request`; маршрутизация и фазы приложения не запускаются.

Ошибки некорректных pseudo-заголовков перехватываются без финализации запроса и обработки отложенных событий. Значения пути, которые могли бы вызвать финализацию ошибки URI, пропускаются; обычные случаи декодирования URI входят в область цели. Заголовки кадров HTTP/2 и фрагментация сетевого чтения отдельно проверяются в IF11 и IF15.

```sh
./fuzz/scripts/fuzz.sh smoke NGX-IF17 --max-len 4096
```

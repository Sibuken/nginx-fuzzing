# NGX-IF08 — TLV расширения PROXY protocol

Байт 0 задаёт произвольный числовой тип TLV. Оставшиеся байты разбираются функцией `ngx_proxy_protocol_read`; если разбор заголовка версии 2 успешен, цель вызывает `ngx_proxy_protocol_get_tlv` для всех публичных имён верхнего уровня и вложенных SSL-полей, неизвестного имени и выбранного числового типа.

Цель дополняет `NGX-IF06`: IF06 проверяет разбор заголовков версий 1 и 2, а здесь проверяются структура TLV, преобразование `ssl_verify` и вложенные SSL TLV.

# NGX-IF10 — примитивы HPACK

Цель проверяет настоящий декодер Хаффмана HPACK в nginx целиком и по заданным входом фрагментам, сравнивая статус, состояние и результат. Через обвязку, добавляемую только при сборке, также проверяется иначе статический декодер целых чисел переменной длины с каждым из четырёх префиксов, используемых представлениями HPACK.

Цель охватывает два побайтовых примитива декодирования HPACK. Она не строит HTTP-запрос, не изменяет динамическую таблицу заголовков, не проверяет pseudo-заголовки и не тестирует последовательность CONTINUATION: для этого нужна более полная модель соединения и запроса HTTP/2.

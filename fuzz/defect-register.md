# Реестр дефектов фаззинга

Реестр объединяет crash-артефакты двух кампаний по первопричинам: 272 finding NGX-OSS-HTTP сведены к двум дефектам, 11 200 finding NGX-IF07 — ещё к двум. В каждом описании указан один представитель и ссылки на первичные логи; остальные однотипные артефакты подтверждают повторяемость того же симптома.

Оба интерфейса собраны с ASan и UBSan, а ошибки UBSan завершали процесс с кодом 77. Для всех crash-findings повторы без санитайзеров завершились с кодом 0. Это подтверждает воспроизводимость диагностики UBSan, но не штатного падения production-бинарника. Исправленный код или компенсирующие меры не применялись; результаты ниже не следует трактовать как проверку исправления.

В NGX-OSS-HTTP также зафиксированы три `slow` finding (61, 84 и 73 мс при повторе); устойчивое зависание не подтверждено, поэтому они не включены в реестр дефектов. Подробные отчёты кампаний: [NGX-OSS-HTTP](runs/NGX-OSS-HTTP/20261006T095528Z-campaign-6-c77d96c9/report.md), [NGX-IF07](runs/NGX-IF07/20261007T212722Z-campaign-1-ed50cba0/report.md).

## NGX-OSS-HTTP

### NGX-OSS-HTTP-UB-01 — арифметика нулевого смещения от NULL

1. **Идентификатор дефекта:** `NGX-OSS-HTTP-UB-01` (227 однотипных crash-артефактов).
2. **Фаззинг-цель:** `NGX-OSS-HTTP`, кампания `20261006T095528Z-campaign-6-c77d96c9`.
3. **Модуль:** nginx, core I/O (`ngx_write_file`) и сохранение тела HTTP-запроса.
4. **Файл исходного кода:** [`src/os/unix/ngx_files.c:208`](../src/os/unix/ngx_files.c) — `buf + written`.
5. **Тип по санитайзеру:** UBSan, некорректная арифметика указателя — применение нулевого смещения к `NULL`; ASan-ошибки для этой группы не зарегистрированы.
6. **Тип по методике:** «Некорректная обработка длин буферов с данными» — нулевой размер записи не исключает арифметику над отсутствующим буфером.
7. **БДУ ФСТЭК / CWE:** CWE-758, Reliance on Undefined, Unspecified, or Implementation-Defined Behavior ([описание CWE-758](https://cwe.mitre.org/data/definitions/758.html)).
8. **Входной вектор:** protobuf text-format HTTP `request`/`reply`; представитель [`crash-05c4e04764588025aa72160480ef569df33843b4`](runs/NGX-OSS-HTTP/20261006T095528Z-campaign-6-c77d96c9/artifacts/crash-05c4e04764588025aa72160480ef569df33843b4), SHA-256 `360ae2a203ccf37fba5189038445cd6dde62c7225d62d70d02508741422be3ee`, 30 513 байт. Вход проходит обработку chunked-тела и приводит к записи нулевого размера во временный файл.
9. **Параметры запуска:** Linux/amd64; libFuzzer fork mode `-fork=1`, `-ignore_crashes=1`, `-max_len=65536`, `-timeout=10`, `-rss_limit_mb=2048`, `-seed=1`; batches по 300 с, интервал проверки покрытия 300 с, плато 7200 с. Сборка: `-fsanitize=fuzzer,address,undefined -fno-sanitize=alignment -fno-sanitize-recover=undefined`.
10. **Логи:** [кампания](runs/NGX-OSS-HTTP/20261006T095528Z-campaign-6-c77d96c9/logs/campaign.log), [UBSan](runs/NGX-OSS-HTTP/20261006T095528Z-campaign-6-c77d96c9/defects/crash-05c4e04764588025aa72160480ef569df33843b4.sanitizer.log), [повтор без санитайзеров](runs/NGX-OSS-HTTP/20261006T095528Z-campaign-6-c77d96c9/defects/crash-05c4e04764588025aa72160480ef569df33843b4.without_sanitizers.log); коды и хеш входа также записаны в [manifest](runs/NGX-OSS-HTTP/20261006T095528Z-campaign-6-c77d96c9/manifest.json).
11. **Воспроизводимость:** стабильная для UBSan: все 227 входов группы при повторе завершились кодом 77; без санитайзеров — кодом 0. Представитель дополнительно завершился кодом 0 в проверочной сборке `-O2` с `_FORTIFY_SOURCE=2` без ASan/UBSan (28 мс). Падение обычного бинарника не воспроизведено.
12. **Комментарий:** при `buf == NULL`, `written == 0` выражение вычисляет `buf + written`, что UBSan считает недопустимым. По имеющимся логам через полученный указатель не выполняется чтение или запись байтов; переполнение буфера и порча памяти не обнаружены. Неопределённое поведение остаётся реальным дефектом корректности.
13. **Разметка:** истинный дефект (UBSan подтверждает нарушение правил языка); не ложноположительный результат. Эксплуатация с повреждением памяти или выполнением кода не подтверждена.
14. **Принятые меры и решение:** 227 артефактов сгруппированы по одной первопричине; просмотрены исходный участок и стеки; входы повторно запущены с UBSan и без санитайзеров, представитель проверен в production-профиле `-O2`/`_FORTIFY_SOURCE=2`. Симптом в production не воспроизвёлся, поэтому исправление nginx и компенсирующие меры не назначены. Минимальный вход и логи сохранены для повторной проверки; при смене компилятора или production-профиля проверку следует повторить.
15. **Результат контрольного прогона:** входы группы повторно исполнены на production-сборке без санитайзеров: завершение штатное, код 0, аварийного завершения нет. Представитель также прошёл `-O2`/`_FORTIFY_SOURCE=2` проверку за 28 мс. Патч не применялся, поэтому регрессионный прогон именно исправленного кода неприменим; результат подтверждает отсутствие воспроизведения на проверенной production-конфигурации.

Поскольку исправление не требовалось и не применялось, прогон после патча неприменим; результат фиксирует отсутствие воспроизведения на проверенной production-конфигурации.

## Ограничения интерпретации

«Истинный дефект» здесь означает подтверждённое нарушение контракта C/API, обнаруженное UBSan. Это не равнозначно подтверждённой удалённой уязвимости. Данные кампаний подтверждают повторяемость UBSan-диагностик и отсутствие ненулевого завершения при повторах без санитайзеров; для двух представителей NGX-OSS-HTTP также записана отдельная проверка `-O2`/`_FORTIFY_SOURCE=2`. Проверки исправленного кода нет ни для одной группы.
